# MotoSaaS Customer & Dealer Flutter Mobile App

This repository contains the **single Flutter** application that serves both **customer** and **dealer staff** experiences for the MotoSaaS platform.

- Guest browsing & vehicle discovery (including 3‑D showroom via the Showroom3D API).
- Customer OTP login/registration flow.
- Staff login (dealer code + username/password) – separate navigation stack.
- Ownership portal, service booking, lead & enquiry submission.
- Clean‑architecture layers (core, shared, features) with Riverpod 3.x, GoRouter, and Dio.

> The Flutter project lives under the `mobile/` directory and is completely independent of the .NET backend services.
